# Sujithra Yesurathinam | Ideas into Action

A seven-section portfolio with a bold plum, coral, and warm-ivory visual identity, a portrait-led homepage, larger readable type, and responsive navigation. Pages use animated entrance transitions, a rotating editorial orbit in page headers, a reading-progress thread, scroll-triggered section reveals, staggered diagrams, and subtle hover motion; visitors who prefer reduced motion receive reduced animations. On touch devices, a horizontal swipe navigates through the pages in the same order as the navigation links; floating previous/next arrows provide an additional way to browse. A corner counter records actual page visits through the included Node.js server and stores the running total locally in `.portfolio-data/visits.json`. It counts page loads, not unique people, and does not record visitor identities. The Learning page presents qualifications in an animated timeline and features an animated NPTEL certificate gallery (`assets/images/nptel-*.png`). The About page maps key career disciplines and includes a personal-interest section; Strategy & Operations pairs an execution-cycle diagram with a streamlined working-signature pathway across analysis, coordination, and communication. Learning connects skills in a toolkit map, Research presents an editorial bibliography, and Projects uses a guided-project pathway instead of repetitive card grids. The Contact page links to email and LinkedIn and includes a message form that opens an email draft in the visitor’s configured mail app; the visitor reviews and sends it there. The resume page offers concise and detailed formats generated from shared site data. Its PDF export control appears only in the local portfolio preview; a public static page cannot securely prevent visitors from using their browser’s own print or save features on content that is visible to them.

## Run locally

Install Node.js, then run `npm run dev` in this folder and open [http://127.0.0.1:4173](http://127.0.0.1:4173). Development mode always displays zero and never changes the live visitor total. The server listens on `0.0.0.0` by default so deployment platforms such as Render can reach it; it prints the local preview address as `127.0.0.1`. To restrict a local run to this computer, set `HOST=127.0.0.1` before starting it. The server has no package dependencies. In Windows PowerShell, if script execution policy blocks `npm.ps1`, use `npm.cmd run dev` instead; this invokes npm's Windows command launcher without changing the system execution policy.

For deployment, use `npm start` as the start command. This enables the counter only for public hostnames; requests through localhost and private IP addresses do not increment or display the live count. The total counts public page loads, not unique people, and may include repeat visits or automated browsers. By default, it is stored in `.portfolio-data/visits.json`. Deployment filesystems may be temporary, so attach persistent storage and set `VISITOR_COUNT_FILE` to a file on that storage (for example, for a Render disk mounted at `/var/data`, set it to `/var/data/visits.json`). Without persistent storage, the counter may reset when the service restarts or is redeployed. Static-only hosting cannot run this counter API.

## Add a portrait

Your supplied portrait is used on the homepage in `assets/images/sujithra-yesurathinam.png`. Image drag-saving and image context menus are disabled as a casual deterrent. A public webpage cannot prevent screenshots or direct retrieval of a publicly served image; do not publish a photo unless you are comfortable with viewers saving a copy. The Strategy & Operations page includes the EV91 company logo (`assets/images/ev91-logo.png`), with direct links to the EV91 website, public LinkedIn company profile, and Riderz delivery partner app.

## Edit content

Update profile details, career history, academic history, focus areas, tools, hobbies, projects, books, and publications in `assets/js/content.js`. The About page shows the birthday as day and month only; the year is not displayed. Both resume formats at `resume.html` are assembled from shared profile data, so content edits are reflected there automatically. The Resume icon in the header opens both formats to view. The “Save PDF” control is available when opening the portfolio through its local preview (`localhost` or `127.0.0.1`); it is hidden on a public host. This is a convenience restriction, not secure access control—restricting printing of public content requires a private, authenticated hosting service. Page layouts are in `assets/js/site.js`; design and responsive styles are in `assets/css/styles.css`.
