# Sujithra Yesurathinam | Ideas into Action

A seven-section portfolio with a bold plum, coral, and warm-ivory visual identity, a portrait-led homepage, a current-focus snapshot based on documented responsibilities, larger readable type, and responsive navigation. Pages use animated entrance transitions, a rotating editorial orbit in page headers, a reading-progress thread, scroll-triggered reveals for copy, cards, diagrams, and resume sections, staggered timelines, and subtle hover motion; visitors who prefer reduced motion receive reduced animations. On touch devices, a horizontal swipe navigates through the pages in the same order as the navigation links; floating previous/next arrows provide an additional way to browse. The Learning page presents qualifications in an animated timeline and features an animated NPTEL certificate gallery (`assets/images/nptel-*.png`). The About page maps key career disciplines and includes a personal-interest section; Strategy & Operations pairs an execution-cycle diagram with a streamlined working-signature pathway across analysis, coordination, and communication. Learning connects skills in a toolkit map, Research presents an editorial bibliography, and Projects uses a guided-project pathway instead of repetitive card grids. On the Contact page, the email link and message form open a pre-addressed Gmail compose page in the current tab; visitors may need to sign in to Gmail, then review and send the draft. The page also links to LinkedIn. The resume page offers concise and detailed formats generated from shared site data. Visitors can use their browser’s print or save features on content visible to them.

## Run locally

Install Node.js, then run `npm run dev` in this folder and open [http://127.0.0.1:4173](http://127.0.0.1:4173). The server listens on `0.0.0.0` by default so deployment platforms such as Render can reach it; it prints the local preview address as `127.0.0.1`. To restrict a local run to this computer, set `HOST=127.0.0.1` before starting it. The server has no package dependencies. In Windows PowerShell, if script execution policy blocks `npm.ps1`, use `npm.cmd run dev` instead; this invokes npm's Windows command launcher without changing the system execution policy.

For deployment, use `npm start` as the start command.

## Add a portrait

Your supplied portrait is used on the homepage in `assets/images/sujithra-yesurathinam.png`. Image drag-saving and image context menus are disabled as a casual deterrent. A public webpage cannot prevent screenshots or direct retrieval of a publicly served image; do not publish a photo unless you are comfortable with viewers saving a copy. ## Edit content

Update profile details, career history, academic history, focus areas, tools, hobbies, projects, books, and publications in `assets/js/content.js`. Both resume formats at `resume.html` are assembled from shared profile data, so content edits are reflected there automatically. The Resume icon in the header opens both formats to view. On the Resume page, choose Short or Detailed, select “Save PDF,” then choose “Save as PDF” in the browser’s print dialog. The selected resume format is the one printed. Page layouts are in `assets/js/site.js`; design and responsive styles are in `assets/css/styles.css`.
